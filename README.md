<h1 align="center">Endless Defence</h1>

<p align="center"><em>An endless survival game built with LÖVE 2D — made for practice.</em></p>

<p align="center"><strong>Status: Work in Progress 🚧</strong></p>

---

## About

<p align="justify">Endless Defence is a small survival game where you play as a lone defender against an endless swarm of red dots. The red dots keep coming and one single hit is enough to end your run — so your only options are to attack them before they reach you, or dodge out of the way and stay alive for as long as you can. The game is currently unfinished and is being built as a personal practice project to learn game development with LÖVE 2D.</p>

## Controls

<p align="justify">Movement is handled with either the WASD keys or the arrow keys, whichever you prefer. Press the Spacebar to attack. Timing matters — attack too late and a red dot will slip through and end your run instantly, so keep moving and keep swinging.</p>

| Action | Key |
| :--- | :--- |
| Move | `W` `A` `S` `D` or Arrow Keys |
| Attack | `Space` |

## How to Run

<p align="justify">This game is built with LÖVE 2D, so you will need the LÖVE runtime installed on your machine before you can play. Once LÖVE is installed, simply double-click the <code>Run.bat</code> file in the project folder and the game will launch. If you prefer running it manually from a terminal, you can also execute <code>love .</code> from inside the project directory.</p>

1. Install [LÖVE 2D](https://love2d.org/) (version 11.x or newer).
2. Download or clone this repository.
3. Double-click `Run.bat` — or run `love .` from the project folder in a terminal.
